Usage

Import modules in your Wren code like this:

// Import core xs engine classes
import "xs/core" for Render, Input, Audio, SimpleAudio, File, Json, Device, Data

// Import math utilities
import "xs/math" for Vec2, Math, Color

// Import entity-component system
import "xs/ec" for Entity, Component

// Import pre-built components
import "xs/components" for Transform, Sprite, Body

// Import containers
import "xs/containers" for Grid, Queue

// Import utility tools
import "xs/tools" for ShapeBuilder

Module Overview

Each module provides classes and functions for specific functionality:

  • xs/ec - Entity and Component base classes
  • xs/components - Pre-built component implementations
